# STEMMate Namibia

### Offline-First STEM Session Planning Application

## About
STEMMate Namibia is a web application designed to help STEM facilitators organise and manage educational activities, especially in areas with limited internet connectivity.

## Features
- Search and filter STEM activities.
- Save activities for offline access.
- Create and edit session plans.
- Manage synchronisation queues.
- Handle simulated synchronisation conflicts.
- Manage kit requests.
- Record participation counts.
- View session plans.

## Technologies
- HTML
- CSS
- JavaScript
- Browser Local Storage
- GitHub

## How to Run
1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Navigate to the `html` folder.
4. Open `index.html` using a Live Server.
